# Sri Rohith Fitness Gym – Website

Folder structure:
- index.html        – the page (must keep this name for GitHub Pages)
- css/style.css     – all styling
- js/script.js      – small script (auto-updates the footer year)
- images/           – logo.png, hero.jpg, gym-photo.jpg

## Deploy on GitHub Pages
1. Create a new repository on GitHub.
2. Upload everything inside this folder (index.html, css, js, images) keeping the same folders.
3. Settings → Pages → Source: "Deploy from a branch" → Branch: main, folder / (root) → Save.
4. Your site goes live at https://<your-username>.github.io/<repository-name>/
